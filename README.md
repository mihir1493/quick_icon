# quick_icon
A smart icon generator that transforms any image into a fresh, theme-matched icon.

### Summary
Simply upload an icon from Google Images (or anywhere), and the tool recreates new icons it in a clean, customizable style — perfect for PowerPoint, presentations, or design projects. It analyzes the original icon’s shape, theme, and visual language, then generates new icons you want based on the prompt you provide while maintaining the same look and feel.
